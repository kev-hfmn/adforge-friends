# Local Geist fonts

Geist Latin and Geist Mono Latin, variable weights 100 to 900, copied unchanged from the installed Next.js 16.1.7 distribution (`next/dist/next-devtools/server/font/`). The app uses `next/font/local` so builds do not need Google Fonts access. Social images use Takumi's built-in Geist.

Upstream: https://github.com/vercel/geist-font
